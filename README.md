# Stem for Cursor

Stem gives Cursor durable, user-controlled memory that can be recalled across AI conversations and tools.

## Install

Install Stem from the Cursor Marketplace, then complete the Awase sign-in and OAuth consent flow when Cursor prompts you.

For direct installation before the marketplace listing is approved, use the [official Cursor install link](https://cursor.com/en/install-mcp?name=stem&config=eyJ1cmwiOiJodHRwczovL2F3YXNlLmRldi9zdGVtIn0%3D).

## MCP endpoint

Stem uses the hosted Streamable HTTP endpoint:

```text
https://awase.dev/stem
```

No API key is stored in this repository. Cursor discovers Stem's OAuth metadata and opens the Awase authorization flow for each user.
